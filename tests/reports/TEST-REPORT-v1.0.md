## 1. Automated tests

### Swift unit (`swift test`)
- Meeting/transcript/folder/chat/summary round-trips through the on-disk store.
- **Speaker rename is metadata-only**: renaming S2→Kainat leaves transcript segment keys
  untouched; rendered transcript shows "Kainat:".
- Malformed `meeting.json` is skipped, not fatal.
- Folder `resolveOrCreate` builds client→project hierarchy, idempotent + case-insensitive;
  removal cascades to children.
- Summary YAML front-matter round-trips (action items with/without owner, quotes escaped).
- **TranscriptAssembler**: mic tokens always S1; system tokens follow diarizer speakers
  (first-appearance → S2, S3…); consecutive same-speaker tokens coalesce; long gaps split;
  tokens outside diarizer segments snap to nearest; volatile results ignored.

### Swift pipeline integration (`SKNOTE_INTEGRATION=1`)
Synthetic 22 s meeting: `system.wav` (Samantha + Daniel voices) + `mic.wav` (Reed voice),
generated by `say`. Fed through `FileAudioSource` → full live pipeline:
- Transcript non-empty; system speech ("launch/checklist") and mic speech ("ship/version
  one") both transcribed.
- Mic segments all S1; **≥2 distinct diarized system speakers**.
- Rename S2→Kainat reflected in rendered transcript.
- `durationSec` reflects audio length; `recording.m4a` written with real data.

### Claude CLI integration (`SKNOTE_AI=1`, live subscription)
Fixture 3-speaker meeting (Saqib/Kainat/Rick):
- **Summary** extracts action items (referencing real commitments), decisions (the launch
  call), things to remember.

- **Auto-categorization** → matches existing "Acme Corp" client folder, confidence > 0.3.

### MCP server (`npm test`, 26 tests)
Spawns the built server via MCP SDK `Client` + `StdioClientTransport` against a fixture data

### Web app (`npm test`, 16 tests)

## 4. Bugs found and fixed during testing

1. **Per-chunk `AVAudioConverter`** corrupted audio at chunk boundaries → garbled ASR.
   Fixed with persistent converters.
2. **Hardened-runtime signing** without `com.apple.security.device.audio-input` silently
   denied the mic (no prompt). Entitlement added.
3. **System-tap IOProc** read the physical output device's silent stream, not the tap's.
   Now selects the ABL buffer matching the tap format's channel count.
4. **ASR finals dropped** at meeting end (consumer task cancelled instead of drained).
5. **Diarization under-split** on live audio (threshold 0.7 merged distinct speakers;
   macOS output processing compresses embedding distances). Lowered to 0.6 after a sweep on
   live captures; verified it doesn't over-split clean audio.
6. **`durationSec` = 0** for file sources; now derived from chunk timestamps.
7. **Claude CLI cwd** inherited the app's, triggering Desktop-access prompts; pinned to the
   data dir.

All re-tested green after fixing.

## 5. Known limitations (documented, v2 backlog)

- Speaker naming during a live meeting works, but the summary is a snapshot — regenerate
  after renaming to propagate names into the summary prose.
- No calendar auto-detection, templates, sharing, or cloud sync in v1 (README backlog).
- Diarization threshold is tuned for meeting/system audio; unusual setups may need tuning.
